# Gatika

Шлюз распределения потоков интернета для Android.

Приложение распределяет трафик по четырём потокам выхода:

- **Потоки 1 и 2** — стандартные условия, бесплатны без ограничения по времени;
- **Потоки 3 и 4** — расширенный доступ, 150 ₽ за 30 дней;
- первые **7 дней** расширенного доступа — бесплатно, один раз на устройство;
- автопродление не подключено.

## Установка

1. Скачайте APK из раздела [Releases](../../releases) — файл для современных телефонов (arm64) или для старых устройств (v7a).
2. Разрешите установку из выбранного источника.
3. Откройте приложение, включите шлюз и при необходимости оформите расширенный доступ на экране «Доступ».

Требования: Android 8.0 или новее.
